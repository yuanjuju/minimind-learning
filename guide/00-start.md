# 从这里开始：把 MiniMind 当作大模型实验台

本仓库不是“我训练过一次”的展示页，而是一条可动手验证的学习路线。基础模型实现来自 [MiniMind 上游](../UPSTREAM_SOURCE.md)；这里的价值在于把它拆成**可观察的问题、可运行的实验、能回到源码核对的解释**。无需重新租 GPU，也可以先完成前四章。

## 学习方法

每章按这个顺序走：先写下自己的猜测 → 运行 CPU 实验 → 对照源码找依据 → 用自己的话解释输出 → 再尝试一个小改动。命令在项目根目录执行，环境准备见 [首页](../README.md#快速开始不租-gpu-也能学)。有正式权重不是这些实验的前提。

| 顺序 | 章节 | 过关问题 | 状态 |
| --- | --- | --- | --- |
| 1 | [Tokenizer 与数据](01-tokenizer-and-data.md) | “字符数”和“token 数”为什么不同？SFT 的 `-100` 屏蔽了什么？ | 有可运行实验 |
| 2 | [Transformer 结构](02-transformer.md) | 输入 `[B,T]` 如何变成 logits `[B,T,V]`？Q/K/V 维度为什么不同？ | 有可运行实验 |
| 3 | [训练、推理与评估](03-training-and-inference.md) | loss 在哪里算？为什么 SFT 推理要套聊天模板？ | 有实验与个人训练案例；系统评估待做 |
| 4 | [扩展方向](04-next-topics.md) | LoRA、DPO、MoE 各改变哪一环？ | 仅源码阅读路线，未完成这些训练 |

## 一张主线图

```text
文本 ─ tokenizer ─> token ID ─ 数据集整理出 input_ids / labels
                           └─> embedding ─> 注意力 + MLP（重复若干层）─> logits
                                                                  ├─ 训练：与 labels 算 loss，反向传播，更新参数
                                                                  └─ 推理：从 logits 选下一个 token，再追加回输入
```

这里的箭头是学习导航，不是声称所有模块都由我原创。上游源码逐文件入口见 [源码地图](../docs/source-map.md)。

## 哪些结果已经真实发生？

单卡预训练、Full SFT、Mac 权重校验和人工对话测试见 [复现记录](../docs/reproduction.md)；CPU 小实验见 [`learning/`](../learning/)。这两类证据不同：小实验解释机制，不是正式模型质量评测；训练完成也不等于 LoRA、DPO 等扩展路线已经实践。每个待实践项目只有在补齐环境、命令、输出和解释后才应改为“已完成”。
