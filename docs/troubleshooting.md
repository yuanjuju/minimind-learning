# 本次复现碰到的问题与边界

| 现象 | 实际原因或判断 | 处理方式 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'datasets'` | 镜像已有 PyTorch，但没装训练脚本依赖 | 在目标 Python 环境按上游 `requirements.txt` 安装所需依赖；先确认用的是同一个解释器 |
| `nvidia-smi` 显存只占约 7 GB，GPU-Util 却接近 100% | 显存占用与 GPU 计算繁忙程度是不同指标 | 同时看吞吐、步耗时、GPU-Util 和功耗；不要仅凭显存低就断言训练“没跑满” |
| 中断后重跑，日志又从头开始 | 是否保存了相应 `save_weight` 的续训检查点、参数是否匹配，需要分别确认 | 检查 `checkpoints/` 中同名 resume 文件，再决定是否使用 `--from_resume 1`；不要把仅有 `out/*.pth` 当作完整断点 |
| WebShell 在 `[0]/[1]` 输入前出现大量 `^[[B` 并报 `ValueError` | 下方向键的转义字符被当成文本输入 | 重新运行，等待提示出现后直接键入 `0` 或 `1` 并回车 |
| 回答到一半停止 | 先看是否触及 `--max_new_tokens`，也可能模型生成结束符 | 在同一提示词上适度提高输出上限再比较；仅延长上限不会提升知识或可靠性 |
| 问“今天星期几”时答错或回避 | 这个小模型没有可靠的实时日期工具 | 不把实时信息问答当作模型知识测试；需要实时信息应接入可信时间工具 |
| Mac 熄屏/浏览器断线 | 云端进程与 Mac 显示器状态不同，但终端连接可能断开 | 用 `tmux` 保持远程会话；云实例关机或被回收前必须确认训练和文件保存状态 |
| `epoch_time` 快到结尾变为 `0.0min` | 脚本中该值按当前速度估算剩余步数 | 不把它理解为总训练耗时；需另看真实开始/结束时间 |

排障先做三件事：确认运行目录、确认 Python 环境、保存完整报错与所用命令。公开提问前移除 SSH 地址、端口、访问令牌、账户信息和平台账单截图。
